# Simple Deep Learning Project

This is a minimal but complete PyTorch deep learning project that trains a small neural network on a synthetic dataset.

## Files
- `train.py`: builds the dataset, defines the model, trains it, and saves the model.
- `requirements.txt`: Python dependencies.

## Run
```bash
cd simple_dl_project
pip install -r requirements.txt
python train.py
```

The script will train a tiny neural network for a few epochs and save the trained weights to `model.pth`.
